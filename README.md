# Pexels API Project

## Project Overview
In this project, you’ll:
- Use JavaScript `fetch` to call the Pexels API
- Store your API key using environment variables
- Hide sensitive data using `.gitignore`

## Instructions
1. Get a free API key from [Pexels](https://www.pexels.com/api){:target="_blank"}.
2. Create a `.env` file and store your key like this:
   ```
   PEXELS_API_KEY=your_key_here
   ```
3. Use JavaScript to load and use the key securely.
4. Add `.env` to `.gitignore`.
5. Build a search form to look up and display images.
